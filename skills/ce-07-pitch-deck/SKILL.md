# CE-07 PITCH DECK (short creative deck)

Run this when the job is a deck to win ideas, inspiration and feedback, usually before the client sends anything. It assembles work from ce-00, ce-04/05 and ce-06. It does not make new films.
Variables: [BRAND], [GOAL], [SLIDES: default 8, range 6 to 8], [DIRECTIONS: default 3].

## MODE
- EXPLORE (default): draft fast, no gates. ALWAYS ON: no invented claims, reviews, quotes or numbers about the brand; mark every inferred item "from your site, please confirm"; use real screenshots, real logo and real packs only; no live site or DNS; no credentials; quote credits before spend.
- BUILD: same, plus approval at the outline and a final check pass by a separate agent. Use when I say "client", "send" or "ship".

## Inputs (ask once, only what is missing)
[BRAND URL] [what exists: ce-00 bible, audit, boards, films, links] [audience for the deck] [length]

## Steps
1. **Gather.** Use what exists. If there is no bible, run ce-00 light intake from the website. If there is no audit, run the ce-04/05 audit (phone and desktop screenshots, competitors). Do not remake finished work.
2. **Outline (show me, then stop).** One line per slide using the default below. I approve or change it.
3. **Build.** Create the deck from the Slides artifact type when it is listed (Artifact quickstart, intent slides). If not, make a .pptx with the pptx skill. Real screenshots and images only. Text in code, never baked into generated images. Keep each slide to one idea.
4. **Check.** Look at every slide as an image. Fix overflow, tiny text, wrong logos or labels, anything inferred but not marked. Then show me.
5. **Hand over.** The deck link or file, plus a one-line list of what is inferred and what we still need.

## Default outline (8 slides; merge or drop to reach 6)
1. **Idea.** The one line the new site says. [BRAND] name from their real logo.
2. **What we saw.** Phone and desktop screenshots of the current site. 3 works, 3 does not. A thin strip of 3 competitor sites: match / beat.
3. **Brand as we read it.** Palette, fonts, voice, flagship products from their site. Marked "from your site, please confirm."
4. **Three directions.** Tame / new direction / spectacular. One board each: palette, type, a homepage sketch. Ask them to pick one.
5. **Homepage and site map.** Section-by-section storyboard with their real products. A small site map idea beside it.
6. **Motion proof.** The finished films or scroll pieces: one still plus a link or short loop each. Shows the ceiling, not the plan.
7. **What we need from you.** Brand guide, logo files, product photos, copy, site and analytics access, who approves.
8. **Questions and next steps.** 3 specific questions (pick A/B/C, love/change/cut per slide, what is off-limits). Rough timeline. No pricing unless asked.

## Rules
- Inferred is not fact. Label it. Never write copy as if the client said it.
- One idea per slide. Few words. Big images.
- Ask for reactions in a form that gets answers: pick A, B or C; Love / Change / Cut on each slide.
- Do not use their name or logo in a way that implies approval or partnership.
- Videos stay as links or short loops; do not bloat the deck.

## Failure modes -> fix
| Problem | Fix |
|---|---|
| Deck looks generic | Use their real screenshots and real products; cut stock-looking art. |
| Too many words | One idea per slide; move detail to speaker notes. |
| Looks like final design | Add "direction, not final" on slide 4 and 5. |
| No brand guide yet | Slide 3 says inferred; slide 7 asks for it. |
| Too long | Merge 5 into 4, drop 6 if no films exist. |

Output style: short, plain language. Ask at most one question at a time.
