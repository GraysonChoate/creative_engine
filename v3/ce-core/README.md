# ce-core (v3.0, draft)
The brain every engine pulls in. Brand-free. Engines: ce-realism, ce-cinematic, ce-motion, ce-web, ce-app. Client work lives in clients/<brand>/, never here.

## The spine (every job, every engine)
| Step | Name | Gate | Core file |

| 1 | Prepare | — | intake.md, asset-studio (from ce-00) |

An engine adds its own thinking inside a step. It never removes a step or a gate.

## Modes
EXPLORE: fast, cheap models, show-and-go at gates (show, then continue unless stopped), free pieces logged not asked.
EXACT: locked specs, full takes, every gate waits.
Named at intake. The engine never upgrades itself from EXPLORE to EXACT.

## Hard rules (every engine)
1. Locks first. Cast, product, location frozen before any clip; checked in every shot.
2. No drift. Build only approved tickets. Extra ideas become proposed tickets, not work.
3. Quote before spend. Every paid ticket shows credits; paid work waits for a yes.
4. Retake cap. Default 2 takes per ticket; then stop and show.
5. The builder never grades itself. Step 7 audit is a separate pass with the ticket sheet in hand.
6. Tool failure is reported, never papered over. A false pass is worse than a fail.
7. Every stop writes a WAKE-UP (freeze.md).
8. Engine lessons are process only (lessons.md). Brand taste stays in the client folder.
